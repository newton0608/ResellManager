# ResellManager

Sistema web para la gestión de inventario, clientes, ventas y cuentas por cobrar de un negocio de reventa con productos provenientes de distintos orígenes.

## 🚧 Estado

Actualmente en fase de planificación y documentación.

## 🛠 Tecnologías previstas

- ASP.NET Core
- Blazor
- Entity Framework Core
- SQLite
