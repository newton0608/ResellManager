# Objetivo
El sistema busca administrar el ciclo completo de abastecimiento, venta, entrega y cobro de artículos provenientes de diferentes orígenes, facilitando el control de inventario y cuentas por cobrar.

- Automatizar la administración de un negocio de reventa de productos provenientes de distintos orígenes (importaciones, compras locales y catálogos).
- Reducir el tiempo empleado en buscar deudas e inventario.
- Facilitar el control de clientes, productos y pagos.
- Permitir acceder al sistema desde un teléfono.
